# [Just Focus](https://github.com/LEB-EPFL/just-focus)

*An open source Python package for vector electromagnetic field calculations in the focus of high NA microscope objectives.*

![Simulation results for intensity in the focus of a high NA microscope objective with an aberrated halfmoon pupil phase pattern](/images/aberrated_halfmoon.png)

## Resources

- [GitHub Repository](https://github.com/LEB-EPFL/just-focus)
- [Coordinate Systems for Modeling Microscope Objectives](link://slug/coordinate-systems-for-modeling-microscope-objectives) : A blog post about the coordinate systems used by the model in Just Focus
- [Focal Field Viewer](https://github.com/LEB-EPFL/focus-field-viewer) : A Streamlit app for real-time focus field visualizations powered by Just Focus

## Skills Demonstrated

- Numerical finite element methods
- Open source software development and maintenance

# [Polarized LED Illuminator](https://kmdouglass.github.io/polarized-led-illuminator/)

*A design for a LED illumination module emitting circularly polarized light for optogenetic control of protein states.*

![A Monte-Carlo ray trace of an LED through an aspheric collimator](/images/led_illuminator.png)

In this project I modeled a LED illumination module using Monte Carlo ray tracing. The purpose was to ensure circularly polarized light of uniform irradiance over the entire volume of a protein solution.

## Skills Demonstrated

- Computer-aided ray tracing
- Radiometric modeling of LEDs
- Developing requirements from discussions with the end user
